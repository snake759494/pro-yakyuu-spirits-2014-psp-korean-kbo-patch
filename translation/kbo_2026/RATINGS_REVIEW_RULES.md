# 로스터와 능력치 재검수 규칙

- 최종 능력치의 단일 명세는 `ratings_review.json`이다. 구단별 이전 JSON의 부분 능력치를 직접 덮어쓰지 않는다.
- `tools/prepare_ratings_review.py`로 공식 ID가 결합된 기록을 환산하고 `tools/kbo_ratings_review.py`에서 619명의 PDN/PDW를 동시에 기록한다.
- 개막 명단은 2026-03-28 공식 등록 ID 290명이다. 외국인 또는 선발이라는 이유로 개막일 미등록 선수를 임의 승격하지 않는다.
- 시즌 중 기록은 개막 능력치에 사용하지 않는다. 구종이 공개되지 않은 선수는 미확인으로 남기며 일본 슬롯의 구종을 상속하지 않는다.
- 29명은 BOOT 생성자, com_sel의 팀 레코드 보정, 시즌 선수 객체 보정을 모두 통과해야 한다. 단순 명단 JSON 변경으로 완료 처리하지 않는다. 경기 출전 인원과 등록 인원은 별개다.
- 포구는 원 게임 함수 088ecc9c / 32바이트의 21비트 위치, 송구는 088ecba0 / 32바이트의 14비트 위치다. 어깨는 088ecaa8이다. 서로 다른 값의 선수로 상세 화면까지 대조한다.
- 최종 ISO 검사: `tools/test_kbo_roster_runtime_fields.py`. 새 페넌트 실제 RAM 검사: `tools/audit_live_kbo_rosters.py`. 옛 SYSTEM 저장 데이터의 잔존 복사본 대신 10개 구단이 연결된 실제 편성 루트를 검사한다.
- 실행 증거는 ISO SHA-256에 묶는다. 빌드가 바뀌면 기존 스크린샷을 새 빌드의 증거로 표시하지 않는다.
- 게임 등급은 공개 기록의 환산값이며 KBO가 공인한 능력치가 아니다. 미확인 구종과 수비 범위·상대 손별 타격 등 추정 항목을 보고서에서 숨기지 않는다.
