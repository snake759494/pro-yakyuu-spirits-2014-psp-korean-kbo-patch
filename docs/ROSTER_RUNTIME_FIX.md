# 2026-10-11 새 페넌트 로스터 오류 수정

> 이 문서는 이전 b717ca4a 빌드의 빈 시스템 저장 환경 검사 기록이다. 사용자 SYSTEM.DAT의 옛 편성이 새 페넌트에도 재적용되는 경로를 놓쳤다. 현재 LG 수정 및 사용자 저장 데이터 검증 결과는 `LG_REBUILD.md`와 `build/runtime_validation.json`을 기준으로 한다. 나머지 9팀의 사용자 저장 환경 오류는 이 이전 기록으로 해결됐다고 판단하면 안 된다.

사용자가 남긴 슬롯1과 스크린샷을 확인하고, 그 장면의 실제 선수 구조체를 분석했다. 이전 검사는 수비 능력 판독 함수만 검사했기 때문에 새 페넌트의 주 포지션과 초기 편성 오류를 잡지 못했다.

## 원인과 수정

- 주 포지션은 수비 능력과 별도로 PDN 레코드 168번 바이트의 3~6번 비트에 저장된다. 투수·포수·내야·외야 분류와 기본 타순의 수비 위치를 이 필드에도 반영했다.
- 새 팀 구성은 INIPLIST가 아니라 PDTPLIST 및 BOOT의 시작 위치/인원 표를 사용한다. 선수 619명과 스태프 50명의 명단을 다시 구성했다. 얼굴 인덱스와 연결되는 INIPLIST는 보존했다.
- 선발·불펜·마무리 및 좌우 상대별 기본 타순의 별도 선수 ID 표를 함께 교체했다.
- 원본 다니시게의 선수 겸 감독 구조를 그대로 사용하면 박진만이 포수에 남는다. 감독은 스태프 슬롯에만 두고 선수 명단에서 제외했다.
- 스태프는 공식 명단 앞 네 사람을 고르는 방식을 폐기했다. 감독 다음은 투수, 타격, 내야수비, 외야수비/주루 담당에 맞춰 배치했다.
- 같은 이름의 선수가 있을 때 엔진이 다른 등록명 선택자를 지정하는 경우가 있다. 한국어 전체 이름 하나만 저장된 레코드도 0~5번 선택자 모두 빈 문자열 대신 전체 이름을 반환하도록 수정했다.

## 새 ISO 실행 검증

독립 PPSSPP 1.17.1에서 설치 데이터 없이 ISO를 콜드 부팅했다. **페넌트 → 처음부터 → 팀 편성**으로 직접 진입했다. 최종 검증에서는 상태저장, 치트, 외부 텍스처, 메모리 수정을 사용하지 않았다. 사용자 슬롯1은 원인 분석용 복사본으로만 사용했다.

- 10개 구단의 1군 확인 화면을 모두 직접 보고 촬영했다. `build/roster_diagnosis/final_{구단코드}_lineup.png`에 있다.
- 초기화된 실제 팀 구조체에서 모든 선수 619명과 스태프 50명의 소속, 이름, 주 포지션, 등록명 선택자, 1군 구분 및 선수/스태프 중복 여부를 대조했다. `live_roster_audit.json`에 선수별 주소와 결과가 있다.
- 삼성 구자욱은 외야, 강민호는 포수이며 박진만은 선수 명단에 없다. 한화 채은성도 이름이 표시된다.
- NC의 투수/야수 등록 화면에서 2군 목록을 스크롤하며 확인했다. 한화 스태프 안내에서 김경문 감독, 양상문 투수코치, 김민호 타격코치 표시를 확인했다.
- 최종 ISO에서 추출한 수정 실행 파일의 MIPS 이름 함수를 선수·스태프 669명 × 등록명 6개 변형으로 실행해 빈 이름이 없음을 확인했다. 관련 회귀 검사 6개와 독립 ISO 검사를 통과했다.

## 남은 범위와 사용 방법

**ISO를 완전히 재시작하고 새 페넌트를 만들어야 한다.** 기존 슬롯1이나 진행 중인 페넌트에는 이전 선수 구조체가 저장되어 있으므로 ISO를 바꾼 뒤 불러오더라도 편성이 자동 교정되지 않는다. 사용자의 기존 저장 파일은 수정하지 않았다.

이번 수정은 분류·등록명·초기 편성·스태프 배치 오류를 대상으로 했다. 게임의 1군 28명(투수12/야수16), 스태프 5명 제한을 유지한다. 기본 타순/선발은 게임용 구성이며 실제 개막 당일 등록 29명 또는 실제 선발 명단과 동일하지 않다. 예비 내야·외야 선수는 공식 그룹만 맞췄으며 일부 세부 주 수비 위치와 신상·능력치는 추가 보정 대상이다.

한화 기존 62명 세트는 공식 2월 64명과 구성 차이가 남아 있다. 공시 자료와 이름을 비교하면 허관회·권현규·배승수·이승현·하동준·유민·이민재가 기존 세트에 없고, 기존 권현·장유호·남지민·이지성 및 동명이인 박준영 한 레코드는 해당 공시 명단과 대응되지 않는다. 따라서 이전 문서의 '2명만 미반영'이라는 설명은 정확하지 않았다. 이 차이를 이번 분류 오류 수정으로 해결했다고 주장하지 않는다.

일부 구단의 편성 미리보기에는 비DH 타순이 표시된다. 기존 정규시즌 DH 코드는 유지했지만 이번에는 경기 시작 후 DH를 재검증하지 않았다. 9개 비한화 구단의 스태프 화면 전체, 모든 2군 이름의 화면 전수 촬영, 새 경기 출전·저장/불러오기·시즌 완주·실제 PSP는 이번 검증 범위 밖이다.
