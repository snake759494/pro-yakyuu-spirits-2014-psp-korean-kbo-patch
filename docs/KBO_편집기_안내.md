# 프로야구스피리츠 2014 KBO 편집기

`KBO_편집기_시작.bat`을 실행하면 기본 브라우저에서 로컬 편집기가 열립니다. Python 3이 필요하며, 서버는 이 컴퓨터의 `127.0.0.1:8765`에만 연결됩니다. 서버 창을 닫으면 편집기가 멈춥니다. 작업을 마친 뒤 서버 창에서 `Ctrl+C`를 누르세요.

선수 619명과 감독·코치 50명의 현재 패치 입력을 불러옵니다. 선수 신상, 등록명, 구단 소속, 1군/2군, 기본 능력치, 모든 수비 위치, 투구 능력/구종, 외형 사진·얼굴 슬롯·피부 팔레트·체형·키·몸무게, 영문 등 이름을 편집할 수 있습니다. 구단 이름/연고지, 한 글자 약칭(기존 대응표 고정), 홈 구장 정보와 모델 슬롯, 유니폼 색상, 로고/유니폼 참고 이미지를 바꾸고, 선발 타순·포지션·로테이션·마무리 및 감독·코치 표시도 수정할 수 있습니다.

게임 레코드 슬롯과 KBO 선수 ID는 기존 포인터/음성/사진 연결을 보호하기 위해 잠겨 있습니다. 신인 영입은 기존 게임 슬롯을 교체하고 등록 명단·외형·음성 자원까지 재배치해야 해서 이 편집기에서 신규 슬롯을 만들거나 삭제할 수 없습니다. 선수의 구단 이동과 1·2군 분류 변경은 가능하며 내보낼 때 10개 구단 1군 29명, 선발/마무리/타순 연결을 검사합니다. 스태프 5개 게임 슬롯은 고정이며 이름·역할을 수정합니다. 게임 구단 ID, 유니폼 리소스 ID, 한 글자 약칭은 앞선 패치 규칙에 따라 고정합니다.

초안은 `editor_data/draft.json`과 업로드한 이미지 `editor_data/assets/`에 저장됩니다. **Codex 입력 패키지 내보내기**는 `editor_data/exports/KBO_editor_input_latest.zip`에 패키지를 저장하고 브라우저로 다운로드합니다. ZIP 안에는 편집 전체 명세 `codex_input.json`, 기준 대비 변경 명세 `diff.json`, 수정 이미지와 Codex 적용 안내가 포함됩니다. 패치 기준으로 사용한 능력치·외형·팀별 신상 원본·타순/로테이션 코드·기존 참고 이미지의 SHA-256도 들어 있어 다른 빌드 입력과 섞이지 않게 확인할 수 있습니다. 패키지를 작업 폴더에 둔 채 Codex에 “최신 KBO 편집기 패키지를 반영해 주세요”라고 요청하면 해당 입력을 검토해 실제 소스 JSON과 구단 자원 작업을 연결할 수 있습니다. 이 단계에서 ISO를 빌드하지 않습니다.

얼굴 사진/로고/유니폼 이미지를 새로 올리면 이미지와 SHA-256은 패키지에 들어갑니다. 사진에서 새 얼굴 텍스처를 합성하는 일, 그래픽을 PSP 텍스처 팔레트·UV에 맞추는 일, 구장 모델·충돌/조명/간판에 변경을 적용하는 일은 이후 Codex 빌드 작업입니다. 편집기에서는 얼굴 사진 자르기 상자 및 눈·코·입 기준점도 조정할 수 있습니다. 기존 3D 얼굴 골격 및 체형 모음의 범위를 넘어 새 모델을 만드는 기능은 없습니다.

선수 평가와 구장 치수는 별도로 제공된 자료에 근거해 검토하세요. 현재 능력치는 공개 기록을 환산한 게임용 추정값입니다. 내보내기는 기본 수치 한계, 선수 연결, 보직/포지션 조합, 구종 입력, 선수 수와 1군 편성, 선발 라인업, 코치 슬롯을 확인합니다. 기준 입력의 SHA-256은 내보낸 패키지에 기록됩니다.

실제 입력 파일과 설명은 [선수 데이터 인계 안내](roster_data/편집안내.md), [구단 외형/구장 적용 규칙](KBO_TEAM_PATCH_RULES.md), [전력 평가 분석](TEAM_STRENGTH_REVIEW.md)을 참고하세요.
