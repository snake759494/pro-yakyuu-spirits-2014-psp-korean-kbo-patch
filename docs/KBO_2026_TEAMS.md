# KBO 2026 전체 선수단 확장판 현황

원본과 같은 폴더의 Korean DEV ISO에 KBO 10팀 선수 명단을 확장 적용했다. 원본 ISO는 변경하지 않았다.

## 공식 기준과 게임 반영

선수단 기준은 KBO가 2026년 2월 10일 공시한 구단별 코칭스태프·소속선수 명단이며, 시즌 개막 1군 등록 변경은 2026년 3월 28일 KBO 등록 현황을 우선했다. 두 기준일은 서로 다르므로 개막 1군 등록이 바뀐 선수는 공식 2월 명단의 같은 포지션 예비 슬롯을 대체했다.

KBO 게임 슬롯은 선수 ID와 음성 키를 유지해 이름·신상·기록을 옮겼다. 9개 구단은 공식 등록 선수 전원을 반영했고, 한화는 기존 검수된 선수·능력·얼굴 세트 62명을 유지했다. 총 적용 선수는 619명이다. 한화는 공식 2월 64명 명단과 일부 구성 자체가 다르며 단순 2명 누락이 아니다. 상세 차이는 `ROSTER_RUNTIME_FIX.md`에 기록했다.

공식 등록 코칭스태프 전체 335명은 각 구단 JSON에 보존했다. 다만 게임은 구단마다 감독·코치 레코드 5개만 제공하므로 감독과 주요 코치 4명씩, 총 50명을 표시·적용했다. 나머지 공식 코치 이름을 팀별 원본 선수 데이터 슬롯으로 억지 변환하지 않았다.

## 능력치·외형의 범위

공식 KBO 시즌 기록을 게임 척도로 환산한 비한화 선수는 138명이다. 나머지 전체 로스터는 공식 한글 이름과 포지션을 반영했지만, 공개 기록 ID가 확보되지 않은 2군 선수는 게임 능력치를 새로 산정하지 못해 원 레코드 능력값을 유지한다. 외국인 등록 이름을 반영하며 고정 크기·ID·음성 키를 보존했다.

KBO 10팀 로고와 기존 유니폼 색상·엠블럼 및 구장명·지역 표기는 종전 빌드 작업을 유지했다. 한화 외 선수의 얼굴 사진, 체형, 등 영문 이름과 구단별 3D 구장 모델은 완성 범위가 아니다. 한화 62명에 적용했던 사진 기반 외형은 유지했다.

## 한계와 검증

단일 리그·10팀 순위·DH 정규시즌 코드는 유지된다. 2014 달력, 포스트시즌과 다음 시즌 로직은 KBO 방식으로 바뀌지 않았다. 2026-10-11 빌드에서는 새 페넌트의 주 포지션, PDTPLIST, 팀별 인원, 선발/불펜과 타순 표를 함께 수정했다. 감독의 선수 명단 중복을 없애고 코치 보직을 재배치했다.

최종 ISO를 독립 PPSSPP에서 콜드 부팅해 새 페넌트의 10개 팀 1군 화면을 직접 확인했다. 실행 중인 팀 구조체의 선수 619명·스태프 50명을 전수 대조했으며, 최종 실행 파일의 등록명 함수도 669명×6개 선택자로 검사했다. 이전 문서의 '화면 미검증' 상태를 이번 실행 증거로 갱신한다.

게임의 1군 28명·스태프 5명 제한과 기존 한화 62명 세트를 유지했다. 예비 선수의 세부 수비 위치·신상·능력치, 공식 개막 당일 엔트리 완전 일치, 비한화 스태프 화면 전체 및 경기 출전/시즌 진행은 완성·검증 범위가 아니다. 일부 구단의 편성 화면은 비DH 타순을 미리보기로 표시한다. 설치 데이터는 재생성하지 않았다.

정적 ISO 검증 및 회귀 검사 6개를 통과했다. 현재 ISO SHA-256: `b717ca4ad3e446fd71674880c3614dfc51488119d66f765344ac5c8340475423`. 원인·증거·잔여 범위는 `ROSTER_RUNTIME_FIX.md`, 선수별 실행 대조는 `build/roster_diagnosis/live_roster_audit.json`, 최종 해시와 검증 범위는 `build/validation.json`, `build/runtime_validation.json`, `SHA256SUMS.txt`에서 확인한다.
