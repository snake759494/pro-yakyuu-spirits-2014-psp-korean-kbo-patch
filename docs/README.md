# 프로야구 스피리츠 2014 PSP v2.00 한글 패치

패치 ISO는 원본과 같은 폴더의 `Pro Yakyuu Spirits 2014 (Japan) (v2.00) (Korean DEV).iso`입니다. 원본 ISO는 수정하지 않았습니다. 파일명의 DEV는 작업 규칙에 따라 유지합니다.

## 현재 개발 ISO: KBO 10팀·DH + 2026 개막 로스터 확장판

최신 피부색·간판 잘림·스윙 판정 글자·경기용 한화 로고·채은성 등록명 수정은 [VISUAL_FIXES.md](VISUAL_FIXES.md)를 참고하세요.

**10팀 선택·팀당 144경기·통합 순위·DH 강제 사용·KBO 구단명**을 적용했습니다. α4는 개인 수비·현재 시즌 타이틀·통산 선수 필터·투수 및 야수 최고 기록의 통합 범위를 넓히고, 홈 순위와 경기 시작 10행 표시를 수정합니다. 경기용 대형 엠블럼 20개도 KBO 로고로 교체했습니다. 2026 공식 전체 소속선수 명단 기준으로 비한화 9개 구단 선수 557명과 기존 한화 62명, 총 619명을 적용했습니다. 구단당 게임 내 감독/코치 5슬롯(총 50명)을 반영하고 전체 공식 스태프 명단은 선수단 JSON에 보존했습니다. 능력치 환산은 공식 기록을 확보한 138명에 한정하며, 한화 공식 공시 명단과 2명 차이 및 상세 미적용 범위는 [KBO_2026_TEAMS.md](KBO_2026_TEAMS.md)에 기록했습니다. 10개 구단 유니폼 색상·공식 로고와 구장명/지역 표기도 반영했습니다. 이번 확장판은 정적 검증만 통과했고 PPSSPP 실행 검증은 하지 않았습니다. 과거 순위 그래프·과거 연도 표창 전체·타 구단 3D 구장·포스트시즌은 완성 범위 밖입니다. 새 페넌트 **풀 시즌**으로 시작하세요.

한화 얼굴 경계/피부톤 보정과 대전 구장 근사 모델 변경은 [FACE_STADIUM.md](FACE_STADIUM.md)를 참고하세요.

한화 영문 등 이름·체형·사진 기반 얼굴과 유니폼 변경 범위는 [HANWHA_VISUAL.md](HANWHA_VISUAL.md)를 참고하세요.

한화 명단·능력 산정·지원하지 않는 항목은 [HANWHA_ROSTER.md](HANWHA_ROSTER.md)를 참고하세요.

이전 시스템 저장 `NPJH50838SS`는 옛 등번호·피부 등 선수 설정을 덮어쓸 수 있습니다. 해당 폴더를 백업·분리한 새 시스템 환경에서 새 페넌트를 시작해야 한화 명단이 정확히 표시됩니다. 이번 빌드는 기존 등록명 설정에서 이름이 비는 경우를 별도로 보정합니다. 자세한 절차와 검증용 백업 위치는 위 안내문에 있습니다.

적용 범위와 실행 방법, 후속 작업은 [LEAGUE_TRIAL.md](LEAGUE_TRIAL.md)를 참고하세요. 이전 한글판 실행 증거는 해당 구 빌드에 한정되며, 이번 시험판은 정적 검사만 통과했고 실기 검증은 하지 않았습니다. 최신 해시·검증 범위는 `build/build_report.json`과 `build/runtime_validation.json`이 기준입니다.

## 적용 내용

- 일반 메뉴, 경기, 페넌트, 스타 플레이어, 스피리츠, 그랑프리, 튜토리얼 등의 문자열과 대사를 직접 번역했습니다. 외부 기계 번역은 사용하지 않았습니다.
- 전작 프로야구 스피리츠6의 번역·작업 지침을 검토하고 원문이 일치하는 번역을 재검수했습니다. PSP의 BDSV·스크립트·PGD 구조에는 별도 도구를 작성했습니다.
- 선수·코치·가상 선수 이름 레코드 2,475개를 처리했습니다. 일반 한글판은 이름 영역 밖의 능력치·ID·음성 키를 보존합니다. KBO 시험판의 한화는 사용자 요청에 따라 능력·포지션·투타·프로필을 별도 명세로 변경하며 ID·음성 키·레코드 크기는 보존합니다.
- 선수 소개 110개, 고유 구종명 91곳, 별도 HELP 블록 971곳도 처리했습니다. 색상·버튼 태그와 서식 인자를 보존합니다.
- 게임 글꼴 네 종류에 한글을 삽입했습니다. 작업 폴더의 9개 폰트를 비교해 원본의 네모난 형태와 획에 가장 가까운 `NanumSquareNeo-cBd.ttf`를 선택했습니다. 비교 근거는 `build/font_selection.json`과 `build/font_comparison.png`입니다.
- 타석·등판 안내, 경기 차수, 중계 표제, 전광판의 초·말 및 구단 약칭까지 별도 이미지 경로를 추적했습니다.
- 메인 메뉴, 경기 HUD, 모드 안내, 순위, 기록, 훈련 등 이미지 문구와 저장 아이콘 9종을 수정했습니다. 원본 팔레트·크기·UV를 유지하고 승인된 글자 영역 밖의 픽셀을 보존합니다.
- 현재 빌드는 UMD 직접 읽기용 아카이브를 갱신하며, 설치용 아카이브는 원본으로 보존합니다. 이전 동기화 빌드와 구분합니다.

정확한 적용 개수·크기·SHA-256은 `build/build_report.json`, 독립 정적 검증은 `build/validation.json`, 해시별 실행 확인 범위는 `build/runtime_validation.json`을 기준으로 합니다.

## 이전 한글 글꼴 확대판의 빌드와 실행 확인

문자열·이름 24,219곳, 이미지 문구 1,290개, 저장 아이콘 9종을 적용했고 적용 제외는 0건입니다. 시험 일정 적용 전 ISO의 SHA-256은 `443dbec99a1dff900b50657e2bd625512973b71be82b06988c93bc9287b486a5`입니다.

독립 PPSSPP에서 설치, 새 스타 플레이어 시작, 저장, 완전 재부팅 후 불러오기, 경기 진입과 직접 타격을 시험했습니다. 글꼴 확대판은 설치·기존 저장 불러오기·메뉴 설명·경기 선수 이름을 재확인했습니다. 이전 타격 및 저장 생성 검증과 최신 화면 증거는 `build/runtime_validation.json`에서 빌드별로 구분합니다. 전체 시즌·모든 모드·PSP 실기 검증은 완료하지 않았습니다.

현재 PPSSPP의 경기 화면에서 일부 작은 특수능력 표시가 검게 겹쳐 보이는 현상이 관찰됐습니다. 해당 보조 표시의 완전한 가독성과 원본 대비 원인은 검증하지 못했으므로, 모든 화면이 완벽하다고 보장하지 않습니다.

## 실행

현재 개발 빌드는 설치 데이터 재생성을 기본적으로 생략합니다. 게임 시작 시 설치는 **아니요**를 선택하고 ISO에서 직접 읽어 실행합니다. 이미 설치 데이터가 있다면 검증용 메모리스틱에서 해당 설치 캐시만 백업·분리하고, 사용자 저장 파일은 보존합니다. 설치 데이터가 필요할 때만 `python -X utf8 tools/build.py --league-trial --with-install-data`로 전체 빌드합니다. 외형 재빌드도 기본적으로 설치 데이터를 건드리지 않습니다.

ISO를 PPSSPP 또는 사용 가능한 PSP 환경에서 실행합니다. 설치 기능은 `--with-install-data`로 만든 빌드에서만 사용하세요. 세이브 스테이트 대신 게임을 완전히 종료한 뒤 새로 부팅하세요. 기존 세이브와 설치 데이터는 서로 다르므로 사용자 세이브를 무작정 삭제하지 마세요.

검증 환경은 `work/emulator`의 독립 PPSSPP입니다. 외부 KBO 텍스처팩과 치트, 세이브 스테이트를 사용하지 않습니다.

## 검증과 범위

- ISO의 원래 크기와 LBA, 4,765개 아카이브 항목의 배치, 번역 영역 밖의 바이트를 검사합니다.
- 삽입한 문자열을 ISO에서 다시 읽고, 설치 데이터 생략 빌드에서는 원본 설치 아카이브 보존을 확인합니다. 설치 데이터를 만든 경우에만 PGD MAC과 직접 읽기 데이터 일치를 검사합니다.
- 정적 통과는 모든 모드의 장기 플레이나 실기 검증을 뜻하지 않습니다. 실행 확인의 구체적인 범위와 화면은 실행 보고서에 기록합니다.
- KBO 구단 로고와 한화 유니폼을 교체했습니다. 다른 팀 유니폼·구장 광고와 일본어 음성은 원본입니다. 한화 홈구장의 모델·주요 간판·명칭은 별도로 변경했으며 실제 대전 구장의 정밀 복제는 아닙니다. 이름 입력의 일본어 변환 사전은 보존하며 두벌식 한글 입력기를 새로 구현한 패치는 아닙니다.
- 고정 길이의 짧은 칸은 간결한 번역이나 복합 글리프를 사용합니다. 작은 글자와 일부 긴 가상 선수 이름은 촘촘하게 보일 수 있습니다.
- 원시 일본어 문자열 후보에는 실행 명령, 숫자 데이터, 입력 사전, 문자표와 개발용 예문이 포함됩니다. 후보 수를 미번역 문구 수 또는 번역률로 표시하지 않습니다.

## 재현

원본 ISO, 선택된 로컬 폰트와 Python, `requirements.txt`의 라이브러리가 필요합니다. 번역 기준 자료는 `translation` 폴더의 JSON 및 직접 번역 원고입니다. 기존 번역 소스를 덮어쓰지 말고 보존하세요.

```powershell
python -X utf8 tools/inventory.py
Push-Location work/iso/PSP_GAME/SYSDIR
& ../../../../tools/bin/eboot_decrypt.exe
Pop-Location
python -X utf8 tools/analyze.py
python -X utf8 tools/players.py
python -X utf8 tools/font_slots.py
python -X utf8 tools/build.py --league-trial --check
python -X utf8 tools/build.py --league-trial
python -X utf8 tools/verify.py
```

빌드 전에 이 ISO를 사용하는 테스트 에뮬레이터를 종료합니다. `--check`는 ISO를 쓰지 않고 사전 검사 보고서만 생성합니다. `build/skipped.json`이 비어 있는지 확인하세요. `analyze.py`와 `players.py`는 기존 번역을 보존합니다.

직접 번역의 최종 기준은 `reference_matches.json`, `new_ui.txt`, `new_ui.json`, `script_direct.json`, `players.json`입니다. 길이 조절은 `compact_phrases.json`, 그림 문구는 `textures.json`, 길이 접두어가 있는 로딩 제목은 `tools/loading_titles.py`, 문맥별 한 글자 표시와 고유 구종 위치는 `extra_locations.json`, 단위·포지션 글리프는 `glyph_aliases.json`, 저장 아이콘은 `tools/save_icons.py`에 정의돼 있습니다. 별도 도움말의 직접 번역 원고는 `help_segments.json`과 `help_*.txt`, 선수 소개 원고는 `npb_intro_direct.txt`입니다.

PPSSPP 제어는 공식 WebSocket 디버거 API를 사용합니다. PSP 실기, 전체 시즌 완주, 모든 분기, 애드혹 통신은 별도 검증이 필요합니다.

이전 시험판에서 만든 저장 파일의 아이콘·상세 설명은 다시 저장해야 새 번역으로 갱신됩니다. 시험 설치 캐시의 삭제가 자동 승인 검토에서 차단되어 `work/retained_install_caches`에 격리 보존했습니다. 이 폴더는 빌드나 실행에 사용하지 않습니다.

새 빌드의 선수·구종 명칭은 새 게임 기준으로 확인합니다. 기존 저장 파일에 이미 기록된 명칭은 소급 변경되지 않을 수 있습니다. 이전 개발판과 글리프 배정이 달라졌으므로 그 개발판의 저장 파일은 최종판 검증에 재사용하지 않았습니다.

## 글꼴 가독성 보완

메뉴 설명과 경기 중 이름에 사용되는 한글 글리프를 셀 내부에 꽉 차게 확대했습니다. 실제 획의 바깥 여백을 제거한 뒤 10×10은 9×9, 14×14는 13×13, 18×22는 17×21, 24×24는 23×23 영역에 배치합니다. 글꼴 종류·문자 코드·문자열 폭과 배치는 유지하므로 기존 한글 저장 데이터와 코드 배정은 같습니다. 복합 이름 글리프도 같은 방식으로 확대한 뒤 원래 셀 수 안에 넣습니다.
