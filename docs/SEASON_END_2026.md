## 능력치 상향(V3)과 피부톤 수정 (2026-10-13 추가)

- 원본 게임 척도는 일본 개막 1군조차 컨택 중앙값 44, 파워 52로 낮다. KBO 환산값도 이 수준이어서 선수들이 약해 보였다. 어깨(타자 전원 63), 회복(전원 84), 포구·송구도 사실상 고정값이었다.
- `tools/realism_scale_2026.py`: 기록 순위는 그대로 두고, KBO 1군의 분위 p를 원본 개막 1군 분포의 분위 p^0.6에 대응시켰다. KBO 중위 선수가 원본 1군 상위 약 34%, KBO 최상위가 원본 최상위가 된다. 어깨는 포지션·외야 보살·포수 도루저지율, 포구·송구는 수비 적성, 회복은 2026/2025 출장 수로 개인차를 만들었다. 구종은 직구와 변화구를 따로 원본 1군 등급 분포에 맞췄다. 구속은 실측값 그대로이다.
- 결과 예: 김도영 컨택71/파워99/주력85, 오스틴 74/99, 디아즈 67/82, 박해민 주력91·수비90, 박영현 포심 구위6, 류현진 포심 제구5. 1군 타자 컨택 중앙값은 47에서 49, 상위 5%는 66에서 69가 되었다. 어깨 중앙값은 63(고정)에서 68(분산)이 되었다. 팀 선택 전력 막대도 올라갔다.
- 피부: 게임 피부 팔레트의 밝기 순서는 2>0>4>1>5>3이다(GMCOMMON ARM0nP/HEADn). 기존 코드는 1·2를 점점 어두운 값으로 잘못 사용했다. 그래서 국내 선수 169명이 갈색(1)이나 엉뚱한 값을 받았다. 국내·아시아 선수는 원본 일본 선수 기본값 0, 백인 외국인은 2, 라틴계 중간 톤은 4, 짙은 갈색은 5, 검은 피부는 3을 쓴다. 외국인 56명은 공식 사진을 육안 검토해 `translation/kbo_2026/skin_types.json`에 지정했다. 검은 피부는 세베리노·카메론·에레디아·디아즈·알칸타라, 짙은 갈색은 페라자·로드리게스이다.

## 피부톤 재수정 (2026-10-13 2차)

- 직전 피부 수정은 잘못됐다. 원본 일본 외국인 선수의 값을 직접 확인한 결과, 피부 유형은 0=일본인, 3=백인(메신저·머튼·엘드레드), 4=라틴계(카브레라·페냐·고메스), 5=흑인(발렌틴·블랑코·밀리지)이었다. 팔 팔레트 밝기로 추정했던 이전 순서가 틀렸다. 지금은 국내·아시아 0, 백인 3, 라틴 중간 톤 4, 검은 피부 5로 지정한다.
- 더 큰 원인은 얼굴 텍스처 합성이었다. 사진을 3D 머리 모델의 음영 색(어두운 갈색)에 맞추고 있었다. 그 결과 패치 얼굴의 볼 평균이 RGB 147/102/69로, 원본 일본 선수 얼굴 184/128/94보다 크게 어두웠다.
- 수정 내용(`tools/hanwha_visual.py`의 `match_tone`, `tools/hanwha_portraits.py`의 `match_portrait`, `tools/face_blend.py`):
  - 원본 얼굴 843개에서 피부 유형별 볼 색 중앙값을 측정해 목표 톤으로 삼았다.
  - 슬롯의 원래 얼굴 바탕과 합성된 얼굴 모두 이 목표 톤에 맞춘다.
  - 사진의 측광 그늘을 더 강하게 평탄화했다.
  - 메뉴 초상화에도 같은 방식을 적용했다.
- 결과: 국내 560명 얼굴의 볼 평균이 179/127/92로 원본과 같은 수준이 되었다. 홈런 경쟁 모드 실제 3D 타석 화면(노시환)에서 확인했다(`build/season_end_2026/skin_v4/`).
- 남은 예외: 김민혁의 슬롯 얼굴 파일은 얼굴 텍스처가 없는 구조라 사진 얼굴이 적용되지 않는다. 박주홍은 원 슬롯 얼굴의 영향으로 약간 어둡다.

## 남은 한계 (완료로 주장하지 않음)

- 사용자 조작 실제 경기, 시즌 진행, 기존 페넌트 저장 이행은 검증하지 않았다. 경기 중 등 이름은 메뉴 배경 선수(BROOKS)에서만 육안 확인했다.
- 능력치는 공개 기록을 환산한 추정치다. 좌/우 투수 상대 컨택은 같은 값이다(분할 기록 미반영).

- 유니폼: 기존 구단 외형 작업을 유지하고 이번에는 바꾸지 않았다. 2026 시즌 중 바뀐 스페셜/시티 유니폼은 반영하지 않았다.
- 얼굴: 공식 사진을 64×64 기존 얼굴 텍스처에 합성하는 방식이다. 전용 3D 모델이 없는 9명(신규 예비 해치 포함)은 공용 모델을 쓴다.

- `G:\내 드라이브` 사본은 갱신하지 않았다.
