# KBO 10팀·DH 시험판 α4

원본과 같은 폴더의 `Pro Yakyuu Spirits 2014 (Japan) (v2.00) (Korean DEV).iso`가 최신 시험판이다. 원본 ISO는 변경하지 않았다.

## 적용 내용

- 참가 팀 선택을 5열×2행의 10팀으로 제한한다.
- 1군 일정은 10팀 단일 대진이다. 팀당 144경기, 상대별 16경기, 홈·원정 각 72경기, 총 720경기다.
- 페넌트 홈과 상세 순위는 참가 10팀의 모든 상대 전적을 합산해 표시한다. 비참가 2팀의 기록은 제외한다.
- 일정의 DH 판정은 항상 사용을 반환하며, 일정이 없는 날의 타순 준비도 DH를 사용한다.
- 참가 10팀의 정식 이름·약칭과 별도 문자열 필드의 짧은 구단 표기를 KBO 이름으로 변경했다.
- 확대 글꼴 NanumSquareNeo-cBd.ttf와 기존 글리프 배정을 유지한다.

원래 지바 롯데·소프트뱅크 슬롯은 정규시즌 참가와 팀 선택에서 제외한다. 자료 구조를 파괴하지 않도록 내부 12개 팀 저장 슬롯과 원래 2리그 객체, 선수 ID·음성 키는 유지한다. 한화 2026 명단의 능력 변경은 HANWHA_ROSTER.md의 별도 명세를 따른다.

## 실행 방법

1. 이전 실행을 완전히 종료한 뒤 최신 ISO를 부팅한다. 세이브 스테이트를 사용하지 않는다.
2. 게임 설치 데이터를 최신 ISO에서 다시 설치한 뒤 완전히 종료하고 재부팅한다. 사용자 선수·페넌트 저장 파일을 삭제하는 작업과 구분한다.
3. 페넌트를 **처음부터 → 풀 시즌**으로 시작한다. 이전 12팀 페넌트 저장은 이번 규칙 검증용으로 사용하지 않는다.
4. 팀 편성 화면은 5열×2행의 참가 10팀만 선택한다. 내부 저장용 12팀 구조는 유지한다.

검증용 에뮬레이터는 `work/emulator`의 독립 메모리 스틱을 사용한다. 외부 텍스처팩·치트·세이브 스테이트는 사용하지 않으며, 검증을 마치면 종료한다.

## 남아 있는 범위

- 포스트시즌 진출·우승 판정과 다음 해 재생성은 원본 2리그 로직이며 KBO 방식으로 완성되지 않았다. 시즌 말의 결과를 KBO 결과로 해석하지 않는다.
- 팀 선택·달력·기록의 공용 아이콘, 깃발형 로고와 참가 10팀의 경기용 대형 엠블럼 두 종류를 공식 KBO 로고로 교체했다. 유니폼 색상과 구장명/지역 표기, 2026 전체 선수 명단도 적용했다. 비한화 9개 구단은 KBO 공시 인원에 맞춘 선수 557명, 한화는 기존 검수 세트 62명으로 총 619명이다. 구단당 게임 내 감독/코치 5슬롯을 적용했고 전체 KBO 등록 스태프 명단을 source JSON에 보존했다. 공식 기록 기반으로 능력치를 새로 환산한 비한화 선수는 138명뿐이며, 그 밖의 선수는 원 레코드 능력값을 유지한다. 한화는 공식 2026 공시 64명 중 2명 미연결이다. 타 구단 3D 구장, 전 선수 사진·체형·영문 등 이름은 미적용이며 일부 경기 HUD 이미지 약칭은 기존 표기가 남는다. 경기 메인의 DRAGONS·LIONS 등 영문 표시는 내부 리소스 키를 겸하므로 원본을 유지한다.
- 게임 달력은 2014년이며 이번 실험 일정은 3월 28일~9월 16일이다. 실제 2026 KBO 일정을 복제한 것은 아니다.
- 자동 진행 요약 순위는 통합 10팀을 1–5위 / 6–10위로 표시한다. 왼쪽 과거 순위 그래프는 원래 리그 기준이다. 팀 투수·타격·수비 및 개인 투수·타격·수비, 현재 시즌 타이틀, 통산 선수 필터, 투수·야수 최고 기록을 통합하는 코드를 적용했다. 홈 하단과 대진 카드도 통합 순위를 사용하며 경기 시작 순위표는 10행으로 제한했다. 최신 빌드에서 실제 확인한 화면은 실행 보고서를 기준으로 한다. 과거 연도 타이틀·표창·포스트시즌 기록 전체는 아직 통합 검증하지 않았다. 일부 설명과 화면 제목에 원래 2리그 체계 표현이 남는다.
- 144경기 시즌 완주, 포스트시즌, 다음 해, PSP 실기는 미검증이다. 전체 선수단 확장 빌드 자체도 PPSSPP 실기 검증은 하지 않았다.
- 상세 순위의 원래 6팀 상대전적·교류전 보조 페이지는 진입을 막았다. 현재는 10팀 통합 순위 화면만 제공하며, 10×10 상대전적 표의 재구성은 포함하지 않는다. 기존 제목에 남는 ‘다음’ 표시는 추가 UI 정리 대상이다.

## 구현과 재현

`tools/league_trial.py`는 일정만 생성한다. `tools/league_code.py`는 팀 선택, DH, 통합 집계와 표시의 실행 코드 변경 및 PNSTATS의 잔여 행 숨김을 정의한다. 원래 리그 객체를 6팀에서 10팀으로 무작정 확장하지 않고 기존 저장 구조를 유지한다. `translation/kbo_names.json`은 구단 이름과 고정 주소 약칭의 원문 바이트를 기록한다.

```powershell
python -X utf8 tools/build.py --league-trial
python -X utf8 tools/verify.py
python -X utf8 tools/test_league_code.py
```

빌드 전에 에뮬레이터를 종료한다. 일반 한글판 빌드는 `python -X utf8 tools/build.py`이며 동일한 Korean DEV 파일 하나를 갱신한다.

`build/validation.json`은 전체 ISO 배치·승인 영역 밖 바이트·삽입 문자열·PGD 설치 블록과 MAC·720경기 제약을 검증한다. `build/league_code_cpu_test.json`은 MIPS 코드로 순위 정렬 3개 경우, DH 입력 46개, 선택 ID 0~9, 비참가 기록 반복 제외, 수치 객체 10행 생성과 원래 레이아웃 복원을 검사한다. 실제 실행 범위와 해시는 `build/runtime_validation.json`을 별도로 확인한다.

이전 α1의 실행 증거는 `build/baseline_league_alpha1` 보고서 및 `league_*.png`, 이전 한글 글꼴판의 보고서는 `build/baseline_font_fill`에 보존한다. 중복 시험 ISO는 만들지 않는다.

현재 ISO와 연결된 결과는 `build/runtime_validation.json`을 기준으로 한다. 초기 α3에서 팀 기록의 숫자 할당 및 세로 스크롤 오류를 발견했다. 최종 구성은 게임의 기존 12행 리소스에서 10팀을 고정 표시하며, 남는 두 행을 숨긴다. 정적 검사와 CPU 검사는 실제 화면 확인을 대신하지 않는다.

## α4 검증 자료

`tools/league_surfaces.py`는 홈 하단, 공통 순위, 실제 대진 카드가 위치한 `pnteam.elf`, 경기 시작 순위표를 수정한다. `tools/league_titles.py`, `tools/league_feats.py`, `tools/league_records.py`는 현재 시즌 타이틀과 최고 기록, 개인 수비 및 통산 필터를 통합한다. `tools/test_league_home.py`와 `tools/test_league_extended.py`는 MIPS 실행으로 통합 집계와 조회를 검사한다.

`PET_*.CHK` 대형 엠블럼 20개는 참가 구단별 두 표시 파일이며, 원본 128×128 영역에 맞춰 확대한다. 경기 시작 제목 이미지도 KBO 공식전으로 변경한다. 최신 실행은 설치 캐시 없이 UMD 직접 읽기로 확인하며, 최신 설치 데이터의 실제 재설치는 별도 미검증이다. PGD 정적 검사는 수행한다.

코드와 로고만 갱신하는 도구는 각각 `tools/update_league_code.py`, `tools/update_large_logos.py`다. 입력 ISO 해시, 수정 전 바이트, 변경 후 재읽기를 검사하고 빌드 보고서를 갱신한다. 전체 재현 기준은 위의 `build.py --league-trial` 명령이다.

최종 α4 SHA-256: `894bc43be37b17396dc819867f583653a1bbfca6465a4e85ebbc5e6cfb180cb2`.

이 빌드에서 4월 5일~30일을 자동 진행하고 5월 1일 저장·불러오기까지 확인했다. 팀당 29경기 진행 및 115경기 잔여, 홈 카드·하단·상세 표의 순위 일치, 경기 시작 KBO 10팀 표와 11·12위 제거, 삼성·두산 대형 로고를 확인했다. `build/alpha4_final_opening_ranks.png`가 전체 10행이 나타난 실제 경기 시작 화면이다. 에뮬레이터는 종료했다. 개인 기록의 앞선 실행 증거는 `build/alpha4_records_runtime_prior.json`에 해당 ISO 해시와 함께 구분해 보존한다.

## 한화 2026 선수단 추가

한화의 선수·능력·투타·등번호·생일·키를 개막 기준으로 교체했다. 상세 명단, 자체 평가 기준, 코칭 슬롯과 외모/음성/과거 기록의 한계는 [HANWHA_ROSTER.md](HANWHA_ROSTER.md)에 기록한다. 위 α4 해시는 선수단 교체 전 이력이며 최신 ISO는 build/build_report.json 및 SHA256SUMS.txt를 기준으로 한다.
