# 프로야구 스피리츠 2014 PSP v2.00 한글화 계획

## 지시사항
- 질문 없이 자체 판단으로 분석·직접 번역·빌드·검증한다. 외부 기계 번역은 사용하지 않는다.
- 원본 ISO와 작업 폴더의 폰트를 보존한다. 최종 패치 ISO는 원본 옆에 하나만 유지한다.
- 번역 소스·빌드 도구·검증 보고서는 보존하고 재생성 가능한 임시 파일과 시험용 ISO는 정리한다.

## 전작 분석 및 적용 원칙
- 스피리츠6의 AGENTS.md, PLAN.md, 분석·글꼴·검증 도구를 확인했다.
- 선수명은 선수 ID와 전체 신원으로 대조한다. 단순 성씨 치환을 피한다.
- 문자열의 제어 코드, 서식 인자, 색상, 고정 레코드 크기와 비번역 데이터를 보존한다.
- 원본 글꼴의 크기·획·가독성을 작업 폴더의 9개 글꼴과 비교해 결정한다.
- ISO LBA와 크기를 보존하고 수정 대상 밖의 데이터 불변과 빌드 재현성을 검사한다.
- 최종 ISO 해시에 실제 실행 증거를 연결한다. 전체 플레이·실기·저장 검증을 추정하지 않는다.
- PS2의 글꼴 주소, BNDR 헤더, CRC, PCSX2 PNACH는 PSP판에 직접 이식하지 않는다.

## 순서
1. ISO·BDSV 아카이브 전 항목과 암호화 EBOOT/설치용 PGD 구조를 분석한다.
2. PSP 글꼴·문자 인코딩·이미지 텍스트·오버레이의 표시 문자열을 추출한다.
3. 전작 번역과 일치하는 문구를 문맥별로 대조하고 신규 문구를 직접 번역한다.
4. 선수·메뉴·경기·페넌트·스피리츠·튜토리얼·기타 모드와 이미지 문구를 처리한다.
5. 설치 데이터 경로와 UMD 직접 읽기 경로의 일관성을 확보한다.
6. 글꼴 및 문자열 용량·포인터·제어 코드와 비번역 데이터 불변을 검증한다.
7. 원본 옆에 고정 이름의 한국어 ISO를 생성하고 읽기 검증 및 가능한 실행 검증을 실시한다.

## 구현 결과

- PSP BDSV 4,765개 항목, CP932/UTF-8 문자열, 워드 순서가 뒤집힌 이벤트 스크립트를 구분했습니다.
- 이벤트 스크립트는 글자 범위만 바꾸고 명령어·분기·레코드 길이를 유지했습니다.
- 별도 INTR/HELP 블록과 선수 고유 구종 필드를 추가 조사했습니다. 소개 110개, HELP 971곳, 구종명 91곳을 처리하고 이름·구종 외의 선수 능력치 영역은 그대로 유지했습니다.
- 일반 문구와 모든 2,475개 이름 레코드를 처리했습니다. 직접 번역 결과와 길이 조정 원고를 보존합니다.
- 원본 글꼴의 미사용 슬롯을 조사해 네 종류의 글꼴에 같은 한글 매핑을 적용했습니다.
- 4bpp/8bpp 이미지의 SBIB 텍스처·팔레트 연결을 분석했습니다. 실제 분할 UV에 맞게 안내 화면을 수정했습니다.
- GPU 프레임에 사용된 타석 표제의 픽셀을 원본 ISO와 대조해 DEBAN/TRN 외부 팔레트 이미지를 발견했습니다. 타석·수비·등판 28종과 경기 차수 31종을 추가 처리했습니다.
- 저장 아이콘 PNG 9종의 하단 모드명도 교체하고 고정 파일 크기를 보존했습니다.
- 설치 PGD의 블록·테이블·헤더 MAC을 갱신하고 복호화 결과와 UMD 직접 읽기 아카이브를 대조합니다.
- ISO 읽기 검증과 별개로 독립 PPSSPP에서 설치, 메뉴, 이벤트, 저장·불러오기 및 조작을 확인합니다. 각 증거는 실제 사용한 빌드 해시에 연결합니다.

정확한 최신 수치와 검증 범위는 README.md 및 build의 JSON 보고서를 기준으로 합니다. 미확인 기능을 확인 완료로 기록하지 않습니다.

최종 점검에서 전각 공백을 포함하는 표시 문구 109곳을 추가 적용했습니다. 각성 안내의 텍스트 사각형과 조작 안내의 13픽셀 행 간격도 수정했습니다. 정확한 빌드와 시험 범위는 실행 보고서에 기록합니다.
