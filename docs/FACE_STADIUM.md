# 한화 얼굴 경계와 대전 구장 변경

이후 페라자·강백호 피부 설정과 간판의 실제 UV 영역을 추가 수정했다. 최신 내용과 검증 범위는 [VISUAL_FIXES.md](VISUAL_FIXES.md) 및 `build/runtime_validation.json`을 기준으로 한다.

## 사용자 스크린샷

`D:/psp/ppsspp_win/memstick/PSP/SCREENSHOT`의 48장을 목록과 SHA-256으로 기록했다. 특히 00041~00045의 경기 종료/인터뷰 장면에서 얼굴 외곽에 남은 밝은 선과 목의 색 차이를 확인했다. 이 화면들은 사용자가 실행한 ISO 해시를 알 수 없으므로 최종 빌드 실행 증거와 구분한다.

## 얼굴

67명에게 사용하는 사진 합성 코드에서 원본 얼굴 전체를 사진색으로 물들이던 처리를 제거했다. 사진의 피부색과 큰 조명 차이를 원래 얼굴 UV에 맞추고, 눈·코·입의 특징을 유지하며 외곽으로 부드럽게 혼합한다. 흰 사진 배경은 경계에서 확장 제거한다. 원래 귀, 목 연결 부분, 알파, 3D 모델과 팔레트 용량을 보존한다. 메뉴 초상화에도 같은 원칙을 적용했다.

PSP의 64×64 얼굴 텍스처와 기존 얼굴형을 사용하는 보정이다. 실제 선수의 3D 얼굴형을 새로 제작한 것은 아니며 모든 각도를 실물과 같다고 보장하지 않는다.

## 구장

한화의 기존 12번 슬롯을 그대로 사용하면서 마쓰다 스타디움의 낮/밤 모델, 충돌, 조명 및 구장 구조 정보를 별도로 복제했다. 원래 마쓰다 슬롯과 다른 팀의 구장 자원은 그대로 보존한다. 낮/밤 간판 각각 33개와 구장 내 팀 표기를 한화/대전 디자인으로 변경했다. 선택 화면의 구장 사진도 같은 모델로 맞춘다.

명칭은 대전 한화생명 볼파크, 짧은 표기는 대전 볼파크, 기존 미야기/센다이 지역 표기는 대전으로 변경한다. 설치 데이터는 재생성하지 않는다.

선택 근거는 지붕으로 덮이지 않은 야구장, 비대칭 외야, 현대식 관중석 구조다. 기존 게임 모델 가운데 마쓰다를 근사 모델로 선택한 개발 판단이며 대전 구장의 정확한 재현은 아니다. 실제 대전 구장의 8m 몬스터 월, 좌우 거리, 복층 불펜을 구현했다고 주장하지 않는다. 게임 내 잔디와 치수는 복제한 모델에 맞춰 천연잔디, 좌101m/우100m/중앙122m, 펜스2.5m를 사용한다.

근거: [대전시 공식 개장 안내](https://www.daejeon.go.kr/drh/board/boardNormalView.do?boardId=normal_0189&menuSeq=6825&ntatcSeq=1475377281&pageIndex=1), [히로시마 구단 공식 구장 투어](https://secure.panoramic.graphics/publicvr/carp.stadium/).
